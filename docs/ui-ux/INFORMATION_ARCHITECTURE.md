# Information Architecture

Home is content/action-first rather than an app drawer.

Primary destinations:
- Home
- Live TV
- Library
- Online/NanoTube
- Music/Radio/Podcasts
- Games
- Files/Downloads
- System

## Home content order
1. Continue / Resume
2. Live/Now when relevant
3. Recent/frequent content
4. Library/content rows
5. Apps/tools

## Navigation rail
The left navigation rail is collapsed/invisible during content browsing. Pressing Left from the first logical column reveals it; moving back into content collapses it.

## Modes

**Simple Mode** exposes daily media tasks and hides technical controls.

**Advanced Mode** adds Files, Downloads, network sources, storage, diagnostics and other power-user surfaces without changing core navigation semantics.
