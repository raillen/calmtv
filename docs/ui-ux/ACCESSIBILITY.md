# UI Accessibility

Baseline requirements:
- complete keyboard/D-pad navigation;
- visible focus with non-color cue;
- scalable text;
- readable contrast;
- no essential information conveyed by motion only;
- motion reduction option;
- subtitles/language preferences accessible during playback;
- safe-area/overscan support;
- on-screen keyboard path for users without a physical keyboard;
- persistent input mappings recoverable to defaults.

Accessibility is a release gate for core screens, not a post-release polish item.
