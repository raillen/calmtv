# Screen Specifications

## Home
Top status area, optional search entry, Continue row, content rows and minimal app/tool access. No permanent side menu.

## Search
Single query surface with grouped results: local media, games, channels, NanoTube/providers, apps/actions. Local results appear without waiting for network providers.

## Library
Grid/row views with lightweight filters. Artwork loads visible-first. Empty/error states offer the next action.

## Games
Continue Playing, systems and game grid. Launch details expose Continue/New Game and minimal metadata.

## Files/Downloads
TV-friendly list/grid, storage/network roots, copy/move/rename and organizer preview. Destructive operations require clear confirmation.

## Settings
Human language categories: Network, Bluetooth, Audio, Display, Controls, Storage, Library, Downloads, Accessibility, System, About.

## Diagnostics
Readable pass/warn/fail cards with exportable technical detail.

## Display surface

Calm TV renders one navigable surface at a time. The default target is the
primary monitor, and the shell must never stretch the Home across an extended
X11 desktop. A future Display setting may select one output, mirror the same
surface, or expose a read-only companion surface; none of those modes may
create an independent remote focus graph.
