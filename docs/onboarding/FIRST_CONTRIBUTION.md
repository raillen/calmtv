# First Contribution

1. Find or create a Goal-backed issue/task.
2. Use `docs/ATLAS.md` to load only relevant knowledge.
3. Confirm the change does not conflict with an accepted ADR.
4. Work behind an existing contract whenever possible.
5. Add/adjust tests with behavior.
6. Run the smallest relevant suite, then broader gates.
7. Compute Documentation Delta.
8. Request independent review; high-risk work should use a different provider/model when available.
9. Record evidence and compact Project Intelligence.

A first contribution should avoid simultaneously changing Shell navigation, AppManager policy and a media backend unless the Goal explicitly requires a cross-cutting architecture change.
