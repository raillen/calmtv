# Scope

## MVP

The first product milestone includes:

- Debian amd64 image that boots into TV Shell.
- Xorg + Matchbox + GTK3 Home.
- D-pad/keyboard navigation and focus framework.
- AppManager/cgroups resource lifecycle.
- Quick Settings for network, Bluetooth, audio, display, storage and power.
- MediaCore with mpv JSON IPC.
- Local media.
- NanoTube integration.
- IPTV/M3U + XMLTV EPG.
- RetroArch integration for selected 8/16-bit systems.
- File/download manager.
- Optional Firefox ESR kiosk runtime for supported commercial streaming sites.
- Diagnostics, recovery path and basic update/package flow.

## P1/P2 after MVP

- Torrent streaming/download engine for lawful/user-provided providers.
- SMB/network library.
- Podcasts/radio/music polish.
- Phone remote.
- HDMI-CEC.
- Smart Organizer/local LLM fallback.
- More hardware profiles.
- Documentation site and richer project intelligence dashboards.

## Explicit non-goals for V1

- General-purpose desktop replacement.
- Photo gallery.
- RSS/news reader.
- Screensaver/Ambient Mode.
- Always-running browser engine.
- Electron shell.
- 32-bit x86 support.
- 4K guarantee.
- N64/Dreamcast/PSP/Saturn as baseline emulation targets.
- Heavy visual effects, blur compositor, particle UI or permanent video backgrounds.
- Custom Linux kernel/driver maintenance.
- DRM/paywall bypass.
- Bundled piracy-focused indexes.
- Autonomous unrestricted shell agent.
