# Content and Service Policy

The project is source-agnostic infrastructure, not a catalog of unauthorized content.

Allowed product capabilities include:
- user-provided local media;
- user-provided M3U/XMLTV playlists;
- lawful/public-domain/Creative Commons catalogs;
- user-provided torrent/magnet sources;
- provider adapters for sources the user is authorized to access;
- commercial streaming websites through their supported browser paths.

The default distribution must not:
- embed piracy-focused torrent indexes;
- source unauthorized IPTV subscriptions/playlists;
- circumvent DRM, paywalls or service access controls;
- impersonate protected services or ship copied proprietary assets.

Provider architecture must keep source integrations isolated from the Shell so policy, security and distribution choices can evolve independently.
