# Roadmap

Roadmap phases describe direction; completion is defined by locked JSON Goals under `.ai/goals/`.

| Phase | Outcome | Goal |
|---|---|---|
| P00 | Atlas/documentation baseline | P00-G01 — DONE |
| P01 | Bootable navigable shell | P01-G01 — EXECUTING (target gates pending) |
| P02 | System adapters and Quick Settings | P02-G01 — EXECUTING (host evidence partial) |
| P03 | MediaCore, local media, NanoTube, IPTV | P03-G01 — EXECUTING (host evidence partial) |
| P04 | MVP closure: RetroArch, optional streaming runtime, diagnostics, recovery and package updates | P04-G01 — EXECUTING (host evidence partial) |
| P05 | Smart Organizer and remote ecosystem | P05-G01 — PLANNED |
| P06 | Hardening and release candidate | P06-G01 — PLANNED |

## Scheduling rule

Do not pull later-phase functionality into a locked earlier Goal merely because an agent can implement it cheaply. Scope stability is more valuable than feature accumulation.

P04 is the MVP closure phase. Torrent providers, SMB expansion, Smart
Organizer/llama.cpp, phone remote, CEC, richer browser workflows, 4K and
additional emulator systems remain outside this milestone.
