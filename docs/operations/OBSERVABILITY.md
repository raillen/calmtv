# Observability

No remote telemetry is required.

Local observability includes:
- journald logs;
- app lifecycle/crash records;
- systemd cgroup stats;
- performance/boot tools;
- mpv playback diagnostics;
- adapter health status;
- VA-API capability report;
- disk/memory/network summary.

Diagnostics should provide a human summary and an exportable technical report with secrets redacted.
