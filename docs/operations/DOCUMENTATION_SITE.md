# Documentation Site

The site is a generated view of canonical Markdown/JSON under this repository.

Requirements:
- navigation generated from ATLAS/document structure where practical;
- public/internal visibility may differ without duplicating truth;
- search/breadcrumbs/related-doc views are derived;
- broken links and orphaned required docs fail CI;
- Project Intelligence dashboards read durable JSON;
- static-site generator remains replaceable.

Never edit a generated site page as the only source of a product/architecture decision.
