# Supported Formats and Sources

Actual codec support depends on the shipped mpv/FFmpeg build and hardware decode capabilities.

## Planned sources

- Local files and removable storage.
- SMB network media.
- Extended M3U/M3U8 IPTV.
- XMLTV EPG.
- HTTP/HLS media supported by mpv/FFmpeg.
- NanoTube-resolved playback.
- Authorized/user-provided torrent/magnet sources through provider integrations.
- Retro ROM formats supported by selected Libretro cores.

## Planned game platforms baseline

NES, SNES, Game Boy, Game Boy Color, Game Boy Advance, Master System, Mega Drive/Genesis and Game Gear.

## Not guaranteed

4K, modern console emulation, proprietary DRM services, unusual IPTV authentication schemes and every codec on every low-end GPU.
