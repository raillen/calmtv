# How-to — Use Network Media

1. Open **Library** or **Files** → **Network**.
2. Select a discovered SMB server or add one manually.
3. Enter credentials if required.
4. Mark folders as Video/Music/Game sources only if you want them in the library.
5. Playback streams through the normal MediaCore path.

Discovery is optional; direct addresses remain available when mDNS/discovery is unavailable.
