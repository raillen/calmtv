# How-to — Add a ROM Library

1. Open **Games** → **Libraries**.
2. Add a local/USB folder.
3. Run **Scan**.
4. The system identifies common platforms from extension, archive contents where supported, checksum/serial and Libretro-compatible databases.
5. Review uncertain entries.
6. Launch a game; RetroArch starts only for the session and closes when returning Home.

Initial optimized targets: NES, SNES, Game Boy/Color, GBA, Master System, Mega Drive/Genesis and Game Gear. Additional systems depend on hardware benchmarks.
