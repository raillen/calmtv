# ADR-0002 — amd64/x86-64 only for V1

**Status:** Accepted
**Date:** 2026-08-13

## Context

Supporting 32-bit x86 would increase package, browser/DRM, testing and hardware complexity while the intended Atom/Celeron class has viable 64-bit targets.

## Decision

Ship/test amd64 only in V1.

## Consequences

Smaller test matrix and better compatibility with current browser/runtime packages. Old 32-bit-only machines are unsupported.

## Alternatives considered

Multi-arch and 32-bit support were rejected for V1.
