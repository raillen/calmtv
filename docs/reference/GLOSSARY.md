# Glossary

**AppManager** — lifecycle/resource authority for launchable applications.

**MediaCore** — shared media state/player/search/history contract.

**InputAction** — semantic input command independent of physical device.

**FocusManager** — central TV navigation/focus engine.

**Provider** — isolated source integration exposing catalog/meta/stream/subtitle resources.

**LPC/PCA** — Lean Progressive Context / Progressive Context Architecture from Project Atlas.

**Goal** — measurable outcome with protected acceptance and evidence.

**Project Intelligence** — compact durable cost/token/effort/quality/debt history.

**Simple Mode** — daily-use UI with technical surfaces hidden.

**Advanced Mode** — optional power-user surfaces without changing core interaction semantics.
