# Performance Target Reference

Provisional targets before P01 measurement:
- 2 GB RAM baseline.
- idle PSS ≤250 MiB target.
- ≤350 MiB idle hard regression proposal.
- cold boot → Home <20 s target.
- shell ready <2 s target.
- D-pad p95 <100 ms.
- no unnecessary idle redraw/polling.
- one heavy foreground process by default.

Measured values replace estimates in Project Intelligence/evidence; documentation is updated when budgets are formally locked.
