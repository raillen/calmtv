# Context and Goals

The active Goal is the unit of measurable completion. The roadmap is not permission to implement unrelated future features.

Lean Progressive Context order:
1. entrypoint + `atlas.json` + project state;
2. active Goal;
3. relevant ATLAS route;
4. specific doc sections/symbols/tests;
5. targeted expansion;
6. at most single-level isolated delegation when needed;
7. stop when evidence is sufficient.

Do not create persistent task-specific `CONTEXT.md` or `SUMMARY.md` files. Durable discoveries belong in the affected canonical document/ADR; temporary retrieval belongs in runtime context.
