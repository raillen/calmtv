# How-to — Add an App

1. Define the user outcome and Goal scope.
2. Choose a resource class and background policy.
3. Implement the App contract and restorable state.
4. Register navigation destination/cards only through shared UI components.
5. Route media through MediaCore when applicable.
6. Launch external helpers through AppManager/systemd scope rather than raw long-lived processes.
7. Add focus/navigation, lifecycle and error tests.
8. Update user/reference docs only if behavior is user-visible.
