# Compatibility Policy

TV Shell supports hardware through Debian/Linux. The project does not maintain private hardware drivers in V1.

Compatibility claims have tiers:
- Tier 1: release-gated hardware.
- Tier 2: regularly tested.
- Experimental: community/limited evidence.

A device being detected by Linux is necessary but not sufficient for a TV Shell support claim; routing, resume, performance and user workflow still require product-level integration evidence.
