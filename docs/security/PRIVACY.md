# Privacy

Default stance:
- no analytics/telemetry;
- no cloud AI dependency;
- no upload of media library/history by the Shell;
- local search/index only;
- optional network services disabled unless enabled/configured;
- diagnostics are local and user-exported.

If future opt-in telemetry is proposed, it requires an ADR, privacy documentation, explicit consent and a way to inspect/disable collected data.
