# Network and Provider Security

- Validate URL schemes and redirect policy.
- Never concatenate provider/user data into shell commands.
- Apply bounded response sizes/timeouts.
- Treat metadata as display text, not markup.
- Separate credentials from provider metadata/cache.
- Phone remote uses explicit pairing/token and local-network scope.
- Disable/close discovery listeners when feature is off.
- External providers receive the minimum filesystem/network capability necessary.
- IPTV credentials/tokens are redacted from logs and exported diagnostics.
