# Contributing

Start with [`ENTRYPOINT.md`](ENTRYPOINT.md) and [`docs/onboarding/DEVELOPMENT_SETUP.md`](docs/onboarding/DEVELOPMENT_SETUP.md).

Contributions are Goal-driven. Do not implement work that is outside the active locked Goal unless the Goal is explicitly amended. Architecture changes require an ADR under `docs/decisions/`.

Every behavior-changing change must compute a Documentation Delta and update only impacted canonical sources.
