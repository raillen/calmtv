# Security Policy

Security design is documented in [`docs/security/`](docs/security/ATLAS.md).

Until a public repository/security contact is established, do not publish live credentials, private playlists, service tokens, personal media URLs or exploit details in public issue trackers.

High-risk components—Firefox runtime, external providers, torrent engine, Smart Organizer and local LLM execution—must follow the sandbox and least-privilege rules defined by the canonical security documentation.
